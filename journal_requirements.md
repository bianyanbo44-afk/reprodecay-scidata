# Scientific Data Requirements Snapshot

Checked against the Scientific Data submission guidelines, data policies and
editorial/publishing policies on 2026-08-13. Recheck before submission because
journal instructions can change.

## Article type

Data Descriptor describing a repository-hosted dataset.

## Required manuscript structure

1. Title
2. Authors and affiliations
3. Abstract
4. Background & Summary
5. Methods
6. Data Records
7. Data Overview (optional and brief)
8. Technical Validation
9. Usage Notes (optional)
10. Data Availability
11. Code Availability
12. References
13. Author Contributions
14. Competing Interests
15. Acknowledgements (optional)
16. Funding
17. Ethics statement where relevant

## Writing constraints that affect this project

- Title: maximum 110 characters including spaces.
- No dataset brand name in the title.
- Avoid advertising terms such as “novel”, “first”, “AI-ready” and “open”.
- Abstract: recommended maximum 170 words; describe data and reuse, not new findings.
- No conventional Results or Discussion section in a Data Descriptor.
- Data Records describe files, formats, folder structure and fields, not summary statistics.
- Data Overview is optional, limited to roughly one paragraph and 1–2 figures/tables.
- Technical Validation must document checks supporting data quality.

## Data and code gates

- Dataset must be downloadable anonymously for first-round review.
- From the second round onward, data must be public in a compliant formal repository.
- Primary data should be deposited in a repository, not only as supplementary files.
- Data must be released at a level of rawness that supports reuse in community context.
- A short Data Availability statement is required even though Data Records contains details.
- A Code Availability statement is mandatory.
- Previously unreported custom code used to generate/process data must be available
  to editors, reviewers and eventual readers; a GitHub release plus DOI archive is recommended.

## Submission file format

- First-round review requires only one readable PDF containing the complete main
  article, figures, tables and captions; a Word file is not required.
- A revised manuscript must include one machine-readable main article as either
  `.docx` or `.tex`.
- The LaTeX route is permitted, so this project does not require a main-manuscript
  Word deliverable. For revision, references must be embedded in a standalone
  `.tex` file rather than supplied only through a separate `.bib` or `.bbl` file.

## Editorial criterion relevant to strategy

Acceptance is not based on perceived impact or novelty of findings. Reviewers
assess the technical quality of data-generation procedures, completeness of the
description and quality-control evidence. Therefore project quality must come
from execution provenance, validation and reuse readiness rather than a flashy
claim.
