# Final census data-overview figure legend v0.2

**Figure 1 | Selection coverage and static comparison products in the
version-paired census.** **a,** The frozen JOSS frame contains 940 records;
396 pass metadata screening, 372 pass publication-archive eligibility, 345
have a resolved endpoint and 345 yield a paired static extraction record. The
27 endpoint-unresolved records remain explicit in the selection and
endpoint ledgers. **b,** Project-level endpoint-minus-publication medians for
Python source lines, Python source files, syntactic API symbols, declared
dependency records, test Python files and CI workflow files. Points are medians
over the 345 paired projects; horizontal bars are deterministic 95% percentile
intervals from 2,000 project-level bootstrap resamples (seed 20260814). These
intervals are descriptive and are not hypothesis tests. **c,** Proportions of
projects with complete paired parsing and with at least one added, removed or
changed feature in the API, dependency and structure families. Family-specific
denominators and partial states are retained in the source tables. All panels
describe observable static records and selection coverage; they do not measure
runtime compatibility, software quality, maintenance, impact or population-wide
prevalence. Source data are provided with the figure.
